MP3 vs WAV for text to speech

Short answer: choose MP3 for almost everything: sharing, web pages, e-learning and podcast drafts. It is about eight times smaller and sounds the same for speech. Choose WAV when an editing tool or workflow requires uncompressed audio.

Does WAV sound better?

Not here. Text 2 Speech creates the WAV by decoding the generated MP3, so the WAV contains exactly the same sound in an uncompressed container. It does not add detail. Pick WAV for compatibility, for example tools that only import WAV, or to avoid re-compressing an MP3 when you edit and export again. Do not pick it for quality.

When to use which

  • MP3: sharing a voiceover, embedding audio in a web page, uploading to e-learning or podcast platforms, sending by message or email.
  • WAV: importing into a video or audio editor that you will export from again, or any pipeline that requires PCM audio.

Both formats come with the same SRT and VTT subtitle files. See the subtitles guide.

Why 24 kHz?

A 24 kHz sample rate captures frequencies up to 12 kHz, which covers the range that matters for speech intelligibility. It is the format the speech service delivers, so higher rates would only make files bigger.

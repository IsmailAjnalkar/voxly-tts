# SEO / AEO / GEO audit: text-2-speech.com (SAGE remediation)

Date: 2026-10-31 · Branch `seo/sage-remediation` · Author: audit & strategy workstream (Agent 5)
Baseline: **production as served on 2026-10-31** (crawled without JavaScript, sequential requests, bot user agent so the site's page-view counter does not count it).

**About the SAGE scores.** The SAGE report (2026-10-31, overall 63/100) was not provided as a file. The category scores below come from the owner's brief. We cannot rerun SAGE, so **the "after" SAGE score must be measured by the owner** (see `OWNER_ACTION_LIST.md`). SAGE is a third-party analyzer. Where its heuristics conflict with official guidance (Google Search Central, Bing, schema.org, WCAG), we follow the official guidance and say so.

**Classification used for every finding:**
- **Confirmed**: reproduced by us, with evidence in `evidence/`.
- **Heuristic**: an analyzer signal that no official guideline requires. It may still be worth doing if it is cheap and helps users.
- **Optional**: a nice-to-have, with no measurable problem today.

### 2.3 No-JS content check

[`evidence/ssr_check.py`](evidence/ssr_check.py) checks 11 representative pages, with output in `evidence/ssr_check_prod.log`. **11/11 pass**: the home generator form, 6 FAQ answers per language home (`/`, `/es/`, `/ja/`, `/ar/` with `dir="rtl"`), the support-page FAQ, the how-it-works limits table, 75 voice-language rows on `/voices.html`, the real SRT cues on the subtitles guide and the measured byte sizes on the MP3/WAV guide are all in the raw HTML.

### 2.4 Production vs. repository drift (found while mapping)

The production files `/index.html` (served raw) and the rendered `/donate.html` contain **real donation links** (`https://buy.stripe.com/aFa6oIcYQ4QE00O22Q1Nu08`, `https://buymeacoffee.com/text2speech`). **No git ref contains them**: `git log --all -S` finds nothing, and `master` and this branch still have `donate.stripe.com/EXAMPLE-replace-me` and `buymeacoffee.com/yourname`. Production `index.html` was last modified 2026-10-31 14:22 UTC, which means it was edited on the server. `deploy/release.sh` replaces `web/` as a whole, so **deploying this branch as it is would put the placeholder links back on the live site**. This is finding X1 (P0).

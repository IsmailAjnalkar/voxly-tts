# Content changes: entity, answer targeting, citability (2026-10-31)

All pages below are generated by `tools/make_content_pages.py` (run from the repo root:
`.venv/Scripts/python.exe tools/make_content_pages.py`). The generator copies the header, footer,
`<main id="main">` and styles from `web/terms.html`, so re-run it after any change to that template.
At the end of each run it checks every generated page and fails the build on: more or fewer than one H1,
skipped heading levels, duplicate ids, titles over 60 characters, descriptions outside 120–160 characters,
internal links or `#anchors` that do not resolve, and any paragraph/list item/table cell of 80+ characters
that appears on more than one page (all `web/**/*.html` plus the home FAQ, steps and use cases in
`web/i18n-home/en.json`).

What changed on existing pages:
- **how-it-works**: the "Is it free?" question (canonical answer: home FAQ), the limits table and the
  "does not do" list moved out (canonical: `/help.html#limits`, `#limitations`); new sections on the voice
  catalog (dated counts), the pipeline (45 s per request, timing fallback), why the limits exist (measured
  5,000-character run) and the data flow. "No analytics" corrected to "no third-party analytics" plus the
  anonymous page-view counter.
- **all generated pages**: "On this page" TOC on long pages, stable `id`s on every H2, first sentence of each
  section is a direct answer, "Related" links between tool, guides and help, guides' breadcrumb now
  Home › Help › guide, titles shortened to ≤ 60 characters, `TechArticle` author/publisher carry the home
  page's `@id` (`https://text-2-speech.com/#org`), `dateModified` 2026-10-31 (`datePublished` kept at
  2026-10-29 for the older pages).
- **accessibility fixes** (pre-existing axe violations): empty corner `<th>` in the SRT/VTT and MP3/WAV
  tables became `<td>`; the two `<pre>` regions and help's four table regions have unique labels.
- **llms.txt**: new pages, measured generation time, "not available" list, owner/contact line, corrected
  privacy line.

Each FAQ answer stays on one canonical page: the home FAQ owns free / character limit / what to type /
pauses / formats / files online; these pages state facts in tables and link instead of repeating Q&As.
No page has FAQPage markup.
